# Model commands¶

Model commands allow you to manage machine learning models.

You can create and manage models in Python using the [Snowpark Model Registry](/developer-guide/snowflake-ml/model-registry/overview) API.

  * [CREATE MODEL](/sql-reference/sql/create-model)
  * [ALTER MODEL](/sql-reference/sql/alter-model)
  * [DROP MODEL](/sql-reference/sql/drop-model)
  * [SHOW MODELS](/sql-reference/sql/show-models)



To run inference on a model, use one of the following methods:

>   * [Run SQL queries in a warehouse](/developer-guide/snowflake-ml/inference/native-batch-inference-sql)
>   * [Call a service function](/developer-guide/snowflake-ml/inference/real-time-inference-rest-api)
>
